# MP299 — Fuel Station Daily Sales (Dehradun)

SCSE3040 MLOps Mini Project · Group **G119**

The project predicts how many litres of fuel a station in Dehradun will sell per day. The target is `litres_per_day`, and model performance is measured using mean absolute error (MAE) in litres.
